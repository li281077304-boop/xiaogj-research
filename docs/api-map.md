# wtwo API map — static inventory

- Target: `chenzhengduan/blog/wtwo` at `5561802e8fc2ed699f30abc59e5e942269660db2`.
- Analysis date: 2026-10-07.
- Scope: static source inspection only; no frontend execution, no business API calls, no source edits.
- Coverage: recursively searched all 254 tracked files under `wtwo` (including hidden paths; `rg --hidden --no-ignore`) for `/api/`, `apiUrl`, `fetch.get/post/put/delete`, `fetchForm`, `fetchBlob`, `fetchBinary`, `EventSource`; then inspected all 14 `src/api/*.ts` files and runtime call sites. Runtime endpoints in this map are active code; API mentions confined to docs/ and .cursor documentation/examples (5 files), comments, Sentry snippets, and disabled legacy code are excluded from endpoint counts.
- Count rule: deduplicate by HTTP method + normalized URL path/query template (dynamic values rendered `{name}`); wrapper aliases to identical method/path are listed together. Direct browser download / image URLs and SSE are listed separately when transport or HTTP method differs.
- Inventory: 175 active `fetch.*` URL wrappers, of which 2 exact method/path alias pairs reduce this to 173 unique wrapper endpoints. Add 1 SSE endpoint and 7 unique direct GET endpoints (3 QR/image URLs, 4 exam download links) = 181 unique method+URL entries; stable IDs `001`–`181` are assigned once each. The direct selector POST to `/api/Course/QueryCourseTime` is merged into its wrapper endpoint.
- Host categories: `apiUrl` resolves through runtime configuration; `testUrl` is an empty string in `src/store/index.ts`, so `testUrl` login/self-identification routes are also same-origin. Literal `/api/...` routes are same-origin. AI routes use `${apiUrl}/aiagent`. This draft intentionally does not resolve deployment hostnames.
- Auth/permissions: `http.ts`, `http-form.ts`, `http-blob.ts`, `http-binary.ts` attach `WTwo-CompanyID` and `WTwo-AuthToken`; default response handlers reject `ErrorCode=407`. This supports an authenticated company/session requirement for those wrappers. Exact role/permission gates cannot be inferred from frontend code. Native fetch and direct links do not visibly attach those headers; browser cookies/proxy behavior is unknown.
- Model confidence: URL/method/transport = high; request/response = high only when explicit TS types or FormData/Blob are visible, otherwise low/medium; business purpose is a frontend-name inference; server authorization and effects remain unverified.
